# Security Policy

## Supported versions

Security fixes are applied to the default development branch only. Release
support will be defined when the project publishes a versioned release policy.

## Reporting a vulnerability

Do not publish suspected vulnerabilities, credentials, model access tokens, or
private prompts in a public issue. Use the repository host's private security
advisory feature when it is enabled; otherwise contact the repository owner
through the contact method listed on the project page.

Include a minimal reproduction, affected revision, operating system, Python,
PyTorch/CUDA version, GPU model, and the impact. The maintainers will
acknowledge the report and coordinate disclosure through the same private
channel.
